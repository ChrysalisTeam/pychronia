
Pychronia "Leet RPG" Framework
####################################


Official repository: https://github.com/ChrysalisTeam/pychronia

The code written for PyChronia is covered by the MIT license (see the LICENSE file at the root of the repository). This means that you may freely use/modify/redistribute it, even for commercial purposes.

However, note that for commercial projects, you'll have to remove/replace dependencies whose license forbids such uses (some jquery libraries and web templates, especially), or get appropriate licenses from their owners.
We added below a quick summary of the licenses of third-party included modules, to help you assess the impacts of licensing for your own usage.

Other python packages, not embedded, are required to run that framework (see "pyproject.toml") ; refer to their respective websites for licensing information.

Nothing forces you to contribute back the bugfixes or features that you might add to the code, however we'd be very thankful if you gave back your own improvements to the community. ^^
